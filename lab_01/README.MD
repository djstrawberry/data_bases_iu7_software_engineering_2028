# Prison Database (PostgreSQL)

DDL-скрипты создания таблиц, constraints и сценарий автоматической генерации и закрузки массовых тестовых данных (1000+ записей) с помощью Python и Faker.

---

## Структура базы данных

База данных состоит из **6 связанных таблиц**:

1. **`cells`** — Камеры (вместимость, наличие видеонаблюдения, количество охранников, режим).
2. **`fractions`** — Группировки/фракции (название, влияние, удерживаемые камеры, привилегии).
3. **`items`** — Предметы/контрабанда (название, стоимость, редкость, степень риска).
4. **`guards`** — Охранники (имя, склонность к сделкам, внимательность, смена).
5. **`prisoners`** — Заключенные (имя, статья УК, статус, срок, привязка к камере, группировке и боссу).
6. **`deals`** — Сделки (тернарная связь $N:K:M$ между заключенными, предметами и охранниками, дата/время, объем, статус).

## Структура репозитория

```text
.
├── create_tables.sql   # DDL: Удаление и создание базовых таблиц
├── constraints.sql     # DDL: Первичные, внешние ключи и ограничения 
├── copy_data.sql       # DML: Массированная загрузка данных из CSV через \copy
├── data/                  # CSV-файлы с сгенерированными данными
   ├── cells.csv
   ├── fractions.csv
   ├── items.csv
   ├── guards.csv
   ├── prisoners.csv
   ├── deals.csv
   └── generate_data.py       # Python-скрипт генерации данных (Faker)
```
